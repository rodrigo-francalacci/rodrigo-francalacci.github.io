# shared/

Files the pages use from `https://rodrigo.francalacci.com/shared/...`.

- `site.css`, `site.js`, `icons.svg`: the site's style, menu script and icons.
- `vb6-theme.css`: the VB6 house style for the calculators (the master copy).
- `style-demo.html`: every component of the VB6 theme, with the markup to copy.
